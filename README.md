# CalculadoraDeArea_WindowsForms
Aplicativo educacional para calculo de área, dividido em duas telas uma de inserção de medidas e outra para que o usuário possa ver como as contas são feitas

## ✦ Sobre
Projeto pessoal realizado baseado no projeto de cálculo de área proposto em sala de aula, na matéria de programação orientada a objetos(POO), criar um projeto que permita que o usuário selecione a forma geométrica da sua preferência para realizar o cálculo de área, com uma IU e UX clara e tratamento de erros.

## ✦ Funcionalidades
- [x] Calculo de área: Retângulo, Losango, Trapézio, Círculo, Triângulo e Quadrado
- [x] Demonstração de cáculos realizados com fórmulas
- [x] Demonstração visual dos dados
- [x] Tratamento de erros para medidas iguais a zero.
- [x] Botão de limpar para limpar dados existentes.
